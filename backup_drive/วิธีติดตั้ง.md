# สำรองข้อมูลลง Google Drive (ทำครั้งเดียว ~5 นาที)

ใช้บัญชี **kroekphonva@gmail.com** (บัญชีเดียวกับ Firebase)

1. เปิด https://script.google.com → **โครงการใหม่** → ตั้งชื่อ `TawanFarm สำรองข้อมูล`
2. ⚙️ การตั้งค่าโครงการ → ติ๊ก **แสดงไฟล์ Manifest "appsscript.json" ในเครื่องมือแก้ไข**
3. กลับหน้าแก้ไข
   - ไฟล์ `Code.gs` → ลบของเดิม วางโค้ดจาก `Code.gs` ในโฟลเดอร์นี้
   - ไฟล์ `appsscript.json` → ลบของเดิม วางจาก `appsscript.json` ในโฟลเดอร์นี้
   - กด 💾 บันทึก
4. ช่องเลือกฟังก์ชันด้านบน เลือก **setup** → กด **เรียกใช้**
   - ขึ้นขอสิทธิ์ → ตรวจสอบสิทธิ์ → เลือกบัญชี
   - ขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" → **ขั้นสูง** → **ไปที่ TawanFarm สำรองข้อมูล** → **อนุญาต** (เป็นสคริปต์ของพี่เอง)
5. เช็ค Google Drive → มีโฟลเดอร์ **TawanFarm สำรองข้อมูล** + ไฟล์ `tawan_<วันนี้>.json` = เสร็จ

หลังจากนี้รันเองทุกวันที่ 1 ตี 4 · ไฟล์ละไม่ถึง 1 MB · ห้ามแก้ไฟล์ในโฟลเดอร์
